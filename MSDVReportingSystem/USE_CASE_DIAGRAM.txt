System Overview:
The system supports five actors: Admin, Student, Teacher, CSU, and JASSU.
Each actor interacts with the system according to their assigned responsibilities
in violation reporting, monitoring, disciplinary action, appeals, and record
management.


Actors:
1. Admin
   - Manages the entire system
   - Reviews violations and student appeals
   - Assigns sanctions and updates disciplinary status
   - Manages user accounts and student records
   - Views dashboards and analytics
   - Performs data backup and recovery actions

2. Student
   - Logs in to view personal dashboard
   - Views personal violation records
   - Submits appeals for violations
   - Changes password on first login

3. Teacher
   - Logs in and submits violation reports
   - Uploads evidence for student violations
   - Views own submitted reports

4. CSU
   - Logs in and submits violation reports
   - Uploads evidence
   - Views own submitted reports

5. JASSU
   - Logs in and submits violation reports
   - Uploads evidence
   - Views own submitted reports

   |
   |-- View Analytics -----------------------------------------------------------> System


Use Case Flow Summary:
1. User logs in with username and password.
2. System validates role and redirects to the correct dashboard or report form.
3. Staff roles submit violation reports with evidence.
4. Admin reviews incoming violation records and decides sanctions.
5. Students check their violation records and submit appeals.
6. Admin approves or rejects appeals and updates disciplinary action status.
7. Students receive notifications and can view updated outcomes.
8. Admin manages users, records, and reports for full system control.
